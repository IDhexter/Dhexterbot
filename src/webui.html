1. Enviar Alerta de Sistema / Zabbix:
curl -X POST http://10.0.15.235/api/pet -d '{"alertSource":"ZABBIX","alertMsg":"SW02 BAMEX Offline!","alertCount":1}'

2. Comemorar Recuperação / Deploy:
curl -X POST http://10.0.15.235/api/pet -d '{"action":"celebrate","say":"Deploy em Producao OK!"}'

3. Dar Café via Script:
curl -X POST http://10.0.15.235/api/pet -d '{"action":"coffee"}'
